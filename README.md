# flaskApp
Feature Set ver. 0.1:
1) As user, I want to be albe to view posts so that I can see author, post content, including text, date posted
2) As user, I want to be able to log in using my username and password so that I can create posts so that I can write text content and other users could view it.
3) As admin I want to be able to manipulate posts so that I can delete them.
4) As user, I want to access list of the content, so that I can navigate, search and go to read them.
5) As admin , I want to be able to access list of users, so that I can view their names and post they made.
6) As user I want to be able to register by entering my username and password to webpage so that I can start posting.
7) As super admin, I want to be able to promote users to admins.
8) As super admin, I want to be able to delete users.
